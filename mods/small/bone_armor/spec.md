## Mod仕様書: bone_armor

### 背景・動機
- `ARMOR` subtype は base に 2,900 件以上ある最大級のアイテム種別だが、本プロジェクトでは未実装（防具modゼロ）
- 当初は「salvaged armor（廃材防具）」を計画したが、base に `helmet_scrap` / `armguard_scrap` / `armor_junk_plate` 等が既存で重複するため、**base に一式が存在しない「骨防具」**に変更する
- base の骨素材防具は `boots_bone` と `jacket_leather_bone` のみで、胴・頭・腕を覆う骨防具は存在しない
- 本modは ARMOR の `armor` 配列・`material` / `material_thickness`・防具レシピのノウハウを蓄積する

### 追加/変更内容（What）
- 含むもの:
  - 骨防具3点: `bna_bone_cuirass`（胴）、`bna_bone_helmet`（頭）、`bna_bone_armguards`（両腕）
  - 各防具のクラフトレシピ（骨・革・紐を素材とする）
- 含まないもの:
  - 脚・足・手の防具
  - モンスター・採取システムの改変
  - 既存防具の改変

### ゲームプレイへの影響（Why）
- 狩猟・解体で得た `bone` に新たな用途を与え、序盤〜中盤のサバイバル防具の選択肢を増やす
- 既存の chitin 防具（昆虫素材）と同系統の防護性能帯に、入手経路の異なる防具を追加する

### 成功基準
- デバッグメニューで3点をスポーンでき、装備すると防護値・重量・被覆率が表示される
- クラフトメニューに3レシピが表示され、素材で製作できる
- 負荷なくゲームが起動する（Level2）

### スコープ判断
- 新規 type 定義はなく copy-from のみ・新規IDは6件（アイテム3 + レシピ3）のため、本来は小規模mod省略条件に該当する
- ただし `ARMOR` の知見蓄積が主目的のため、設計意図を残す目的で仕様書・設計書を作成する
