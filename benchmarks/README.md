# benchmarks/ — 性能測定用（F-2 正本）

`benchmarks/` は**スクリプトの性能測定専用**とする（2026-09-14 人間決定）。
評価タスク用の分類は `mods/seen/`・`mods/unseen/` 側に分離し、
本ディレクトリに `seen/`・`unseen/`・`random/` の二重 taxonomy は置かない。
旧 `benchmarks/{random,seen,unseen}/` は F-2 で廃止した。

## 配置方針

- 性能測定スクリプト・手順書のみ置く（例: 大規模 mod に対する変換処理時間の計測）。
- 現状は測定スクリプト未整備のため本 README のみ。追加時は本ディレクトリ直下に
  `<対象>_<内容>.md` または `<対象>_bench.py` として置き、本 README から参照する。
- 標準ライブラリ（`time` / `perf_counter`）で足りる間は外部依存を増やさない。

## pytest-benchmark 導入判断

- **導入しない**（2026-09-14、F-2）。理由: 現状の測定対象は手動の都度計測で十分で、
  CI の perf リグレッションゲートも不要。dev 依存を最小に保つ。
- 将来 CI で性能回帰を検出する必要が生じたら再検討する。

## 関連

- 評価タスク分類の正本: `mods/seen/`（学習済み）・`mods/unseen/`（未知タスク）
- 空ディレクトリ維持用の `.gitkeep` は本ディレクトリ直下に置く。
