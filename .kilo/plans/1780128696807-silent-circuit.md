# Pipe Pistol Mod 実施計画

## 概要

9mm単発式の即席パイプ拳銃（pipe pistol）を追加する小規模mod。既存のパイプライフル（ライフルスキル・長銃身・ストック付き）に対し、拳銃スキルで扱える短銃身の即席火器。

## スコープ判定（小規模mod省略条件チェック）

| 条件 | 判定 |
|---|---|
| 新規ID 5個以下 | **○** 3個（item, recipe）|
| copy-fromのみ | **○** `gun_base_handgun_manual` から継承 |
| 既存システム拡張のみ | **○** 新システムなし |
| 既存同カテゴリからの派生 | **○** パイプライフル (`rifle_22`) の拳銃版 |

→ **Step 1（仕様書）・Step 2（仕様書レビュー）省略可。Step 3（計画書）から開始。**

## アイテム仕様

| フィールド | 値 | 根拠 |
|---|---|---|
| `id` | `ppis_9mm_pipe_pistol` | プレフィックス `ppis_` |
| `type` | `"ITEM"` (subtypes: `["GUN"]`) | 既存全銃器定義で明示（copy-from時も必須） |
| `copy-from` | `gun_base_handgun_manual` | RELOAD_ONE, RELOAD_EJECT, NO_TURRET, skill=pistol 等を継承 |
| `flags` | `[ "RELOAD_EJECT", "EASY_CLEAN" ]` | パイプライフル準拠で明示（RELOAD_ONE, NO_TURRET, ALLOWS_BODY_BLOCK は継承） |
| `name` | `{ "str": "9mm pipe pistol" }` | プレーンなstr形式 |
| `description` | `"A home-made pistol. It is a pipe with a crude grip and hammer mechanism, designed to strike the single 9mm round it holds."` | |
| `looks_like` | `"glock_19"` | 外見参照 |
| `ascii_picture` | `"sm_pipe_gun"` | パイプガン共通のアスキーアート |
| `weight` | `"1200 g"` | パイプライフル1953gより軽く、ashot 828gより重い（スチール+ウッド） |
| `volume` | `"900 ml"` | パイプライフル1610mlより小さく、ashot 800mlよりやや大きい |
| `longest_side` | `"35 cm"` | ashot準拠（拳銃サイズ） |
| `barrel_length` | `"203 mm"` | ashot準拠（短銃身ピストル） |
| `price` | `"75 USD"` | パイプライフル100USDより安価 |
| `price_postapoc` | `"5 USD"` | パイプ武器共通の崩壊後価格 |
| `material` | `[ "steel", "wood" ]` | パイプライフル準拠 |
| `ammo` | `[ "9mm" ]` | 既存弾薬IDを使用 |
| `ranged_damage` | `{ "damage_type": "bullet", "amount": -1 }` | Glock 19準拠（短銃身による弾速低下） |
| `dispersion` | `650` | パイプライフル550より悪く、ashot 900より良い |
| `durability` | `6` | パイプ武器共通 |
| `loudness` | `35` | パイプライフル25より大きく、9mmの発射音を反映 |
| `clip_size` | `1` | 単発式 |
| `reload` | `200` | パイプライフル・継承ベース共通値（即席単発の標準リロード速度） |
| `barrel_volume` | `"120 ml"` | パイプライフル(610mm→360ml)の比例換算 (203mm→120ml) |
| `blackpowder_tolerance` | `60` | パイプライフル準拠（黒色火薬使用可） |
| `valid_mod_locations` | `[ [ "sights mount", 1 ] ]` | パイプライフル準拠（簡素な照準器のみ） |
| `pocket_data` | `[ { "pocket_type": "MAGAZINE", "rigid": true, "ammo_restriction": { "9mm": 1 } } ]` | パイプライフル準拠の固定マガジン |
