# 計画書: 小規模Mod 2種の作成

## タスク概要

`mods/small/` に小規模modを2種類新規作成する。

1. **Mod 1 — `makeshift_wire_saw`**: 簡易クラフトツール（ワイヤー製のこぎり）
2. **Mod 2 — `mixed_grain_bar`**: 新規飲料/食品（雑穀バー）

## 前提条件

- CDDAソース `external/cdda/` が配置済み（0.I RC想定）
- `rules/CORE.md` の命名規則・単位・必須フィールドを遵守
- `templates/design_template.md` の構成に従う
- 各modは `validate.sh` → `link_mod_for_test.sh` → ゲーム起動確認 の順で検証

## 確認事項（実装前にユーザー確認が必要）

- [ ] Mod prefix の確定:
  - Mod 1（ワイヤーのこぎり）: `mws_` と仮定
  - Mod 2（雑穀バー）: `mgb_` と仮定
  - 別のprefixを希望する場合はこの計画書のID欄を更新すること
- [ ] レシピ難易度・所要時間に不満があれば調整

## Mod 1: `makeshift_wire_saw`（簡易クラフトツール）

### 目的
スクラップ素材から作れる簡易のこぎりを追加。序盤の木工作業を補助。

### スコープ
- **含む:** 新規TOOLアイテム1種、製作レシピ1種
- **含まない:** 専用耐久度システム、電動化、収納ケース

### 参照ファイル
- `external/cdda/data/json/items/generic.json` → `makeshift_hammer`（TOOL構造参考）
- `external/cdda/data/json/recipes/recipe_others.json` → 製作レシピ参考

### ファイル構成
```
mods/small/makeshift_wire_saw/
├── design.md
├── modinfo.json
└── data/
    ├── items.json
    └── recipes.json
```

### アイテム設計（`items.json`）

```json
[
  {
    "id": "mws_makeshift_wire_saw",
    "type": "ITEM",
    "subtypes": ["TOOL"],
    "name": { "str": "makeshift wire saw" },
    "description": "A crude saw made from a strand of wire with two wooden handles.  It can cut through wood, but slowly and inefficiently.",
    "weight": "300 g",
    "volume": "250 ml",
    "longest_side": "40 cm",
    "price": "0 cent",
    "price_postapoc": "25 cent",
    "to_hit": { "grip": "solid", "length": "hand", "surface": "point", "balance": "neutral" },
    "material": ["steel", "wood"],
    "symbol": ";",
    "color": "light_gray",
    "qualities": [["SAW_W", 1]],
    "flags": ["BELT_CLIP"],
    "melee_damage": { "cut": 3 }
  }
]
```

### レシピ設計（`recipes.json`）

```json
[
  {
    "type": "recipe",
    "activity_level": "LIGHT_EXERCISE",
    "result": "mws_makeshift_wire_saw",
    "category": "CC_OTHER",
    "subcategory": "CSC_OTHER_TOOLS",
    "skill_used": "survival",
    "difficulty": 1,
    "time": "10 m",
    "reversible": true,
    "autolearn": true,
    "components": [
      [["wire", 2], ["wire_barbed", 2]],
      [["stick", 2], ["2x4", 1]]
    ]
  }
]
```

### 根拠・注意点
- `SAW_W`（木工用のこぎり）品質1はバニラの `saw`（品質2）より低く、簡易ツールとして妥当
- `weight` `volume` はバニラの小型工具（`knife_swiss_army`: 100g等）より大きく、実用的なサイズに設定
- `reversible: true` で分解可能にし、序盤の素材回収を容易にする
- `activity_level` は `LIGHT_EXERCISE`（手作業、軽い体動作）

## Mod 2: `mixed_grain_bar`（新規飲料/食品）

### 目的
雑穀と蜂蜜を練った携行食を追加。高カロリーで長期保存可能な補給食。

### スコープ
- **含む:** 新規COMESTIBLEアイテム1種、製作レシピ1種
- **含まない:** 専用包装、複数フレーバー、変質アニメーション

### 参照ファイル
- `external/cdda/data/json/items/comestibles/drink.json` → `coffee`（COMESTIBLE構造参考）
- `external/cdda/data/json/recipes/` → 食品レシピ参考

### ファイル構成
```
mods/small/mixed_grain_bar/
├── design.md
├── modinfo.json
└── data/
    ├── items.json
    └── recipes.json
```

### アイテム設計（`items.json`）

```json
[
  {
    "type": "ITEM",
    "subtypes": ["COMESTIBLE"],
    "id": "mgb_mixed_grain_bar",
    "name": { "str_sp": "mixed grain bar" },
    "weight": "120 g",
    "color": "yellow",
    "comestible_type": "FOOD",
    "symbol": "%",
    "quench": -5,
    "calories": 350,
    "description": "A dense bar made from ground grains and sweetened with honey.  It's dry and crumbly, but packed with energy for long journeys.",
    "price": "1 USD",
    "price_postapoc": "50 cent",
    "material": ["wheat"],
    "volume": "120 ml",
    "charges": 1,
    "phase": "solid",
    "flags": []
  }
]
```

### レシピ設計（`recipes.json`）

```json
[
  {
    "type": "recipe",
    "activity_level": "LIGHT_EXERCISE",
    "result": "mgb_mixed_grain_bar",
    "category": "CC_FOOD",
    "subcategory": "CSC_FOOD_BREAD",
    "skill_used": "cooking",
    "difficulty": 2,
    "time": "20 m",
    "batch_time_factors": [80, 4],
    "autolearn": true,
    "components": [
      [["flour", 2]],
      [["honey_glassed", 1], ["honey_bottled", 1], ["syrup", 1]],
      [["water_clean", 1], ["water", 1]]
    ],
    "tools": [
      [["surface_heat", 10, "LIST"]]
    ]
  }
]
```

### 根拠・注意点
- `calories: 350` はバニラの `granola`（370 kcal）や `crackers`（260 kcal）と同等の携行食レベル
- `quench: -5` は乾燥した食感を表現（バニラの `jerky` 等と同様）
- `batch_time_factors: [80, 4]` は同カテゴリの食品レシピ（`hardtack` 等）を参考
- `tools` に `surface_heat` を要求し、乾燥・加熱工程を表現
- `honey_glassed` / `honey_bottled` / `syrup` はバニラで存在する甘味料ID

## 実装順序

1. Mod 1 の `design.md` 作成
2. Mod 1 の `modinfo.json` 作成
3. Mod 1 の `data/items.json` 作成
4. Mod 1 の `data/recipes.json` 作成
5. `bash scripts/validate.sh mods/small/makeshift_wire_saw/` で Level1 検証
6. Mod 2 の `design.md` 作成
7. Mod 2 の `modinfo.json` 作成
8. Mod 2 の `data/items.json` 作成
9. Mod 2 の `data/recipes.json` 作成
10. `bash scripts/validate.sh mods/small/mixed_grain_bar/` で Level1 検証
11. 必要に応じて `link_mod_for_test.sh` / `check_mods.sh` で Level2 検証

## テスト計画

| レベル | 内容 | 手順 |
|---|---|---|
| Level1 | JSON構文OK | `validate.sh` を各modに実行 |
| Level2 | ゲーム起動OK | `link_mod_for_test.sh` → CDDA起動 → mod有効化時エラーなし |
| Level3 | 意図通り動作 | デバッグメニューでスポーン、クラフトメニューでレシピ確認 |

## リスクと対策

| リスク | 対策 |
|---|---|
| `activity_level` の値が不正 → ゲーム起動エラー | バニラの同カテゴリレシピを参照して選定済み |
| `name` フィールド形式（`str`/`str_sp`）ミス | CORE.mdに従い、TOOLは`str`、COMESTIBLEは`str_sp`を使用済み（ただし飲料/食品は`str_sp`が推奨。`mixed grain bar`は`str`で問題ないか要確認） |
| 依存アイテムID（`wire`, `flour`等）が存在しない | バニラの `external/cdda/data/json/` を参照し、存在を確認済み |
| `qualities` `SAW_W` のスペルミス | バニラの `makeshift_hammer` 等から `qualities` の書式を確認済み |
