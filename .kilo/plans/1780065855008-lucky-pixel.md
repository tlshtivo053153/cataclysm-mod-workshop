# Plan: Improvised Traps Mod (即席トラップ)

## Summary

CDDAのtrapシステムを使った**小規模mod**。バニラに存在しない「クラフト可能な簡易トラップ」2種を追加する。
これまで作成されたmod（変異・武器・食品・モンスター・バイオニック・格闘・職業・シナリオ・スニペット）の
いずれとも重複しない**新カテゴリ**。

## Mod Design (設計)

### 仕様（背景・動機）

CDDAには既にnailboard trap（釘板）、caltrops（撒菱）、bear trap（罠）、land mine（地雷）などのトラップが存在するが、
いずれも製作に中程度の技能や専用素材を要する。序盤のサバイバーでも簡単な素材で即席製作できるトラップを追加し、
拠点防衛やゾンビの足止めオプションを拡張する。

### スコープ

| 含む | 含まない |
|---|---|
| 騒音警報トラップ（空き缶+紐） | EOCを使った複雑な挙動 |
| 廃材スネアトラップ（金属ワイヤー製） | 新規trap actionの定義 |
| 自習レシピ（騒音警報）1種 | 電子部品を使う高度トラップ |
| | 複数レシピ・書籍レシピ |

### 成功基準

1. Level1: `validate.sh` でJSON構文エラーなし
2. Level2: ゲーム起動時、mod有効化でエラーなし
3. Level3: デバッグメニューで各トラップアイテムをスポーン → 設置 → 発動確認

### 詳細仕様

#### 1. 騒音警報トラップ (`tr_imp_trap_noise` / `imp_trap_noise_alarm`)

**trap定義:**
```json
{
  "type": "trap",
  "id": "tr_imp_trap_noise",
  "name": "noise maker",
  "color": "light_gray",
  "symbol": "^",
  "visibility": 2,
  "avoidance": 8,
  "difficulty": 0,
  "action": "bubble",
  "drops": [ "imp_trap_noise_alarm" ],
  "vehicle_data": { "sound_volume": 90, "sound": "CLANK! CLANK! CLANK!" }
}
```

- `action: "bubble"` → 発動時に破裂音。ダメージなし。バニラの`tr_bubblewrap`と同様
- `vehicle_data.sound_volume: 90` → 車両が踏んだ時に大音量（通常のbubblewrapは18）
- `visibility: 2` → やや見えやすい（光る缶が付いているため）
- `avoidance: 8` → ゾンビは回避しない（ニオイも何もないので誘引も回避もしない）

**item定義 (`copy-from: "light_snare_kit"`):**
```json
{
  "id": "imp_trap_noise_alarm",
  "type": "ITEM",
  "subtypes": [ "TOOL" ],
  "copy-from": "light_snare_kit",
  "name": { "str": "noise alarm" },
  "description": "A length of string threaded through a bundle of empty tin cans, with two anchor stakes.  When stretched across an opening and triggered, the cans clatter together loudly, alerting you to intruders.",
  "weight": "1200 g",
  "volume": "1500 ml",
  "material": [ "steel", "cotton" ],
  "use_action": {
    "type": "place_trap",
    "needs_solid_neighbor": true,
    "trap": "tr_imp_trap_noise",
    "moves": 150,
    "practice": 2,
    "done_message": "You string up the noise alarm."
  },
  "flags": [ "SINGLE_USE" ]
}
```

- `light_snare_kit` からcopy-fromしつつ、重量・容積・素材・設置先trapを上書き
- `needs_solid_neighbor: true` → 両端に壁が必要（通路設置型）
- `category` はcopy-from元の `"traps"` を継承

**recipe定義:**
```json
{
  "type": "recipe",
  "activity_level": "LIGHT_EXERCISE",
  "result": "imp_trap_noise_alarm",
  "category": "CC_OTHER",
  "subcategory": "CSC_OTHER_TRAPS",
  "skill_used": "fabrication",
  "difficulty": 1,
  "time": "20 m",
  "autolearn": true,
  "components": [ [ [ "can_drink", 3 ], [ "can_food", 3 ], [ "can_medium", 3 ] ], [ [ "string_36", 1 ], [ "string_6", 1 ] ] ]
}
```

- `activity_level: LIGHT_EXERCISE` — 軽作業（缶に穴を開けて紐を通す程度）
- `autolearn: true` — 自習可能（技能0）
- 素材：飲料缶/食品缶/中缶のいずれか3個 + 糸/紐1本（`can_drink`/`can_food`/`can_medium` はバニラ実在ID）

#### 2. 廃材スネアトラップ (`tr_imp_trap_cans_snare` / `imp_trap_cans_snare`)

**trap定義:**
```json
{
  "type": "trap",
  "id": "tr_imp_trap_cans_snare",
  "name": "scrap wire snare",
  "color": "dark_gray",
  "symbol": "^",
  "visibility": 2,
  "avoidance": 6,
  "difficulty": 0,
  "action": "snare_light",
  "drops": [ "imp_trap_cans_snare" ]
}
```

- `action: "snare_light"` → バニラの軽スネア(`tr_light_snare`)と同じ行動（小型生物を捕縛）
- `visibility: 2` → 金属製で草本製より目立つ
- `avoidance: 6` → 動物がやや避ける（金属臭）

**item定義 (`copy-from: "light_snare_kit"`):**
```json
{
  "id": "imp_trap_cans_snare",
  "type": "ITEM",
  "subtypes": [ "TOOL" ],
  "copy-from": "light_snare_kit",
  "name": { "str": "scrap wire snare" },
  "description": "A simple loop snare fashioned from scrap metal wire and a few bent nails for anchorage.  Tougher than a string snare, making it suitable for slightly larger prey.  It has no means of harming its target, as live meat lasts longer.",
  "weight": "3200 g",
  "volume": "2500 ml",
  "material": [ "steel" ],
  "use_action": {
    "type": "place_trap",
    "trap": "tr_imp_trap_cans_snare",
    "moves": 150,
    "practice": 2,
    "done_message": "You set the scrap wire snare."
  },
  "flags": [ "SINGLE_USE" ]
}
```

- `light_snare_kit` からcopy-from
- 重量3.2kg（light_snare_kitは2.5kg）→ 金属製で重い
- 素材 `steel` → 金属ワイヤー
- レシピは**定義しない**（序盤ではやや高度なため、レシピ未定義＝分解または本でのみ習得可能）

### 検証手順

1. `bash scripts/validate.sh mods/small/improvised_traps`
2. `bash scripts/link_mod_for_test.sh mods/small/improvised_traps`
3. `scripts/check_mods.sh improvised_traps`
4. CDDA起動 → デバッグメニューでアイテムスポーン → トラップ設置 → 踏んで発動確認

### 実装上の注意点

- ITEMの `name` は `{"str": "..."}` 形式（TOOLは `str_sp` 不可）
- `activity_level` は必須（省略するとエラー）
- `copy-from` 使用時、`use_action` 全体を上書きして `trap` 参照先を変更する
- trap定義の `name` は単純文字列（`str_sp` 不可）
- `SINGLE_USE` フラグ必須（設置型トラップアイテム）

### copy-from 継承検証（`light_snare_kit`）

| フィールド | copy-from元の値 | 上書き値 | 備考 |
|---|---|---|---|
| `name` | `"light snare kit"` (平文) | `{"str": "noise alarm"}` | 0.I形式で上書き |
| `material` | `"wood"` (文字列単体) | `["steel", "cotton"]` | 配列で上書き |
| `weight` | `"2500 g"` | `"1200 g"` | 軽量化 |
| `volume` | `"3150 ml"` | `"1500 ml"` | 小型化 |
| `longest_side` | `"80 cm"` | （継承） | 上書き不要 |
| `category` | `"traps"` | （継承） | 上書き不要 |
| `flags` | `["SINGLE_USE"]` | `["SINGLE_USE"]` | 同一値で再宣言 |
| `use_action` | `{type: "place_trap", trap: "tr_light_snare", ...}` | 全面上書き | trap参照先変更 |
