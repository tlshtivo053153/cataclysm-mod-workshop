# Plan: Fix Magiclysm_with_Random_Dungeons-0I Mod Errors

## Context
The mod `PSY_magi_spells_0.I` (Magiclysm_with_Random_Dungeons-0I) has 1685 ERROR entries in debug.log when checked with `./scripts/check_mods.sh PSY_magi_spells_0.I`. The errors fall into these categories:

1. **Undefined flags** (79 errors): `ONLY_ONE` (15), `FANCY` (13), `SUPER_FANCY` (2)
2. **Vehicle part errors** (97 from veh_type.cpp): missing variants, deprecated string definitions, unknown parts
3. **JSON schema errors** (906 from flexbuffer_json.cpp): invalid/misplaced fields
4. **Text style errors** (393 from text_style_check_reader.cpp): spacing/punctuation in descriptions
5. **Translation errors** (46 from translation.cpp): deserialization issues
6. **Item factory warnings**: charges defined but cannot have any

## Step 1: Investigate and Fix Undefined Flags

### 1.1 Check flag definitions in CDDA
- Search CDDA source for correct flag names (`FANCY`, `SUPER_FANCY`, `ONLY_ONE`)
- Likely these flags need to be defined as `json_flag` entries in the mod

### 1.2 Define missing flags
Create a new file or add to existing JSON:
```json
[
  {
    "type": "json_flag",
    "id": "ONLY_ONE",
    "name": "Only One",
    "description": "Only one of this item can be carried."
  },
  {
    "type": "json_flag", 
    "id": "FANCY",
    "name": "Fancy",
    "description": "Fancy item."
  },
  {
    "type": "json_flag",
    "id": "SUPER_FANCY",
    "name": "Super Fancy",
    "description": "Super fancy item."
  }
]
```
