## Mod設計書: scrap_zombie mod

### 目的
- 金属スクラップと融合した新規ゾンビ進化系統を2種追加する
- スクラップゾンビ（中盤）→ スクラップハルク（後半進化）の2段階
- 工業地帯・スクラップ置き場に出現し、倒すと金属素材をドロップ
- 高アーマー・高打撃ダメージ・低速という特徴で既存ゾンビと差別化

### スコープ
- 含むもの:
  - MONSTER 2種: `mon_zombie_scrap`（スクラップゾンビ）、`mon_zombie_scrap_hulk`（スクラップハルク）
  - 死亡ドロップ `item_group` 1種: スクラップメタル・鋼鉄塊をドロップ
  - `monstergroup` same-ID merge: `GROUP_ZOMBIE`（市街地出現）、`GROUP_ZOMBIE_UPGRADE`（進化プール）に注入。CDDAは同一IDのmonstergroupをマージするため、追加エントリのみを記述すればよい
- 含まないもの:
  - アイテム・レシピ追加（death_dropsは既存バニラアイテムのみ使用）
  - 突然変異・職業・シナリオ・格闘術
  - マップ・乗り物・バイオニック

### ターゲットバージョン
- CDDA: 0.I RC

### モンスター仕様

#### mon_zombie_scrap（スクラップゾンビ）

| 項目 | 値 | 根拠 |
|---|---|---|
| copy-from | `mon_zombie_base` | 基本ゾンベの構造を継承 |
| species | `["ZOMBIE", "HUMAN"]` | baseから継承（変更不要） |
| hp | 110 | 通常ゾンビ(80)より硬い、tough(100)よりやや高い |
| speed | 55 | 金属の重みで通常(70)・tough(85)より遅い |
| melee_skill | 5 | tough(6)よりやや低い |
| melee_dice / sides | 3d4 | 通常(2d3)より高い打撃力 |
| melee_damage | `[{"damage_type": "bash", "amount": 8}]` | 金属四肢による打撃 |
| armor | bash: 8, cut: 10, stab: 6, electric: 2 | tough(bash:2, cut:1)より大幅に高い物理装甲 |
| special_attacks | `grab(cooldown:7)`, `bite_humanoid(cooldown:5)`, `scratch_humanoid`, `smash(throw_strength:48)` | copy-from時に完全上書き。PARROT/PARROT_AT_DANGERはtoughのパターンに従い削除 |

| death_drops | `mon_zombie_scrap_death_drops` | スクラップ系ドロップ |

| flags (追加) | SMELLS | tough/hulk等の上位ゾンビに準拠 |
| flags (削除) | STUMBLES | 重量級のため削除（hulkと同様） |
| color | `dark_gray` | 金属質の外観 |
| description | 工業事故で金属と融合したゾンビ。捻じれた金属片が全身に突き出ている。 | |

### 出現設定

**same-ID merge パターン**を使用。バニラと同一IDのmonstergroupを定義し、追加モンスターのみ記述する。CDDAローダーが自動でマージする。

| 注入先monstergroup | モンスター | weight | cost_multiplier | 備考 |
|---|---|---|---|---|
| `GROUP_ZOMBIE` (同一ID定義) | `mon_zombie_scrap` | 10 | 5 | 中盤からの低頻度出現 |
| `GROUP_ZOMBIE` (同一ID定義) | `mon_zombie_scrap` | 5 | 15 | 遅延出現（後半増加） |
| `GROUP_ZOMBIE_UPGRADE` (同一ID定義) | `mon_zombie_scrap` | 30 | — | 通常ゾンビからの進化先として出現 |

`mon_zombie_scrap_hulk` は直接spawnせず、`mon_zombie_scrap` からの進化（half_life: 168 = 約7日）のみで出現。

### バランス検証

**中盤ゾンビ（scrap）:**
- 比較対象: `mon_zombie_tough` (hp:100, speed:85, armor: bash:2/cut:1, melee:3d6+1cut)
- scrapはtoughより高HP(110)・低速(55)・高装甲(8/10)・bash打撃特化(3d4+8bash)
- トレードオフ: 鈍重だが打たれ強く、接近戦では危険

**後半ゾンビ（scrap_hulk）:**
- 比較対象: `mon_zombie_hulk` (hp:480, speed:130, armor: bash:8/cut:12, melee:4d8)
- hulkより低HP(380)・低速(75)だが装甲(14/16)が大幅に高い。打撃力はhulk同等
- トレードオフ: 鈍重だが正面からの撃破が困難。火器・爆発物が有効

### 実装順序
1. modinfo.json
2. data/death_drops.json（依存先を先に作成）
3. data/monsters.json（death_dropsを参照）
4. data/monstergroups.json（monster IDを参照）

### テスト手順
1. `validate.sh` でJSON構文チェック（Level1）
2. `link_mod_for_test.sh` でCDDAに配置
3. `check_mods.sh` でmod読み込み確認（Level2）
4. CDDAを起動、デバッグメニューで以下を確認（Level3）:
   - デバッグモンスタースポーンで `mon_zombie_scrap` / `mon_zombie_scrap_hulk` が出現すること
   - 戦闘時に打撃ダメージ・装甲が意図通り機能していること
   - 死亡時に金属スクラップをドロップすること
   - 市街地で時間経過により自然出現することを確認（または debug spawn group でGROUP_ZOMBIEから出現確認）
