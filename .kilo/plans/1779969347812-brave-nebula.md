# 計画書: 日本語サバイバーノート (jp_survivor_notes)

> **選択**: スニペット拡張

## 設計書

### 仕様

- **目的**: CDDAのサバイバーノート（`note`カテゴリ）に日本語テキストのバリエーションを追加し、日本プレイヤーの没入感を向上させる
- **スコープ**（含むもの）:
  - サバイバーが書いたと思われる手書きメモ・日記の切れ端（`note` カテゴリ拡張）: 10〜15個
  - 避難所や建物の壁に書かれた日本語の落書き（`general_graffiti_snippets` カテゴリ拡張）: 5〜8個
- **スコープ**（含まないもの）:
  - 新規スニペットカテゴリの作成（既存カテゴリを拡張するのみ）
  - アイテム・レシピ・モンスター等の追加
  - 英語テキストの翻訳
- **成功基準**:
  - ゲーム内で日本語のサバイバーノートがランダムテキストとして表示されること
  - ゲーム内で日本語の落書きが表示されること

### ターゲットバージョン

- CDDA: 0.I RC

### 依存関係

- 依存mod: `dda` のみ

## 実装計画

### CDDAデータとの整合性確認結果

| 確認項目 | 結果 | 根拠 |
|---|---|---|
| `note` カテゴリに `name` フィールドがあるか | **なし**（`note_child` のみ使用） | `survivor_notes.json` 全エントリが `{ "id": "...", "text": "..." }` 形式 |
| `note` のテキスト形式 | **引用符で囲む**: `"\"本文\""` | 全エントリ共通。これは「手書きの紙切れ」表現のため |
| `general_graffiti_snippets` のテキスト形式 | **平文**: `"本文"`（引用符なし） | 全エントリ共通。落書きの視覚的表現のため |
| 自動マージの可否 | **可能**（同一 `type` + `category` で定義） | Magiclysm（`note` 拡張）、DinoMod（`general_graffiti_snippets` 拡張）で実証済み |
| `copy-from` / `extend` の要否 | **不要** | 上記modいずれも使用していない |
| `//` コメント行の使用 | **許可**（CDDAローダーが許容） | バニラ・modの双方で広く使用 |
| 日本語（全角文字）の使用 | **問題なし** | `snippet` 型は任意のUTF-8テキストを格納可能。`harvest_drop_msgs.json` 等でも特殊文字使用あり |

### 採用するテキスト形式

```json
// note カテゴリ — 引用符で囲む
{ "id": "jpn_note_1", "text": "\"テレビが最後に映した映像は『緊急事態宣言』の文字だった。\"" }

// general_graffiti_snippets カテゴリ — 平文（引用符なし）
{ "id": "jpn_graffiti_1", "text": "水道は止まっても希望は止められない" }
```

### snippets.json の構成

```json
[
  {
    "type": "snippet",
    "category": "note",
    "text": [
      { "id": "jpn_note_1", "text": "\"テレビが最後に映した映像は『緊急事態宣言』の文字だった。それから二週間、誰にも会っていない。\"" },
      { "id": "jpn_note_2", "text": "\"地下鉄の駅に立てこもって三日目。食料はあと少し。外の音がどんどん近づいている。\"" },
      ...
    ]
  },
  {
    "type": "snippet",
    "category": "general_graffiti_snippets",
    "text": [
      { "id": "jpn_graffiti_1", "text": "水道は止まっても希望は止められない" },
      { "id": "jpn_graffiti_2", "text": "ここに生きている人間がいる" },
      ...
    ]
  }
]
```

### 注意点

- **自動マージ**: 同一 `type` + `category` の定義はCDDAローダーが自動マージする（`monstergroup` と同様の動作）。Magiclysmの `note` 拡張、DinoModの `general_graffiti_snippets` 拡張で実証済み
- **`copy-from` / `extend` 不要**: 同一カテゴリ名で `"type": "snippet"` を定義するだけで結合される
- **他modとのID衝突防止**: `jpn_` プレフィックスを使用。Magiclysm（`magiclysm_note_N`）、DinoMod（`general_graffiti_dino_N`）と競合しないことを確認済み
- **テキスト形式の区別**:
  - `note`: `"\"日本語引用符付きテキスト\""` — バニラの全エントリが二重引用符で囲まれている
  - `general_graffiti_snippets`: `"日本語平文テキスト"` — バニラの全エントリが引用符なし
  - `name` フィールドはどちらも使用しない（`note_child` とは異なる）
- **スニペット参照（`<category_name>`）**: 使用可能だが今回はシンプルに固定テキストのみ使用
- **日本語テキスト**: `snippet` 型は任意のUTF-8テキストを許容。バニラデータの `harvest_drop_msgs.json` 等でも特殊文字使用あり
