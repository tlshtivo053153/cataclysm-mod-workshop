# 計画: Magiclysm_with_Random_Dungeons-0I のパッチ化

## 目的

`mods/Magiclysm_with_Random_Dungeons-0I/`（95 JSONファイル）を Git 管理対象から削除し、代わりに `external/cdda/mods/Magiclysm_with_Random_Dungeons-0G/` に対する変更差分パッチとして保存する。スクリプトによる自動変換と手動修正を分離し、複数の小さなパッチファイルに分割する。

## 前提条件

- **変更前**: `external/cdda/mods/Magiclysm_with_Random_Dungeons-0G/`（Git 対象外、.gitignore）
- **変更後**: `mods/Magiclysm_with_Random_Dungeons-0I/`（Git 管理下、削除対象）
- **シンボリックリンク**: `external/cdda/mods/Magiclysm_with_Random_Dungeons-0I` → `mods/Magiclysm_with_Random_Dungeons-0I/`（削除対象）
- **差分量**: `diff -ruN` で約 117,785 行

## アプローチ概要

1. 0G を一時ディレクトリにコピーし、既存スクリプトを順次適用
2. 各スクリプト適用後にスナップショットを取り、差分を個別パッチとして抽出
3. 全自動スクリプト適用後の残差分を「手動修正」パッチとして抽出
4. パッチを `patches/Magiclysm_with_Random_Dungeons_0G_to_0I/` に配置
5. `mods/Magiclysm_with_Random_Dungeons-0I/` およびシンボリックリンクを削除
6. ドキュメントを更新

## 詳細ステップ

### Phase 1: スクリプトの一時的適合

一部のスクリプトは対象ディレクトリがハードコードされているため、一時的にコピー・修正して CLI 引数を受け付けるようにする。

- `scripts/remove_invalid_fields.py`: ハードコードされた `mod_dir` を `sys.argv[1]` に変更
- `scripts/fix_duplicate_ids.py`: 同等の処理だが、内容差分は手動修正パッチに吸収される想定
- `scripts/convert_price.py`: 既にファイルパスを受け付けるため `find` で一括渡し可能

### Phase 2: 順次パッチ生成

作業ディレクトリ: `/tmp/kilo/patch_work/`


## パッチ構成の補足

| パッチ | 内容 | 対象ファイル数（想定） |
|---|---|---|
| 01_item_types.patch | `type` フィールドの統合と `subtypes` 追加 | 30〜40 |
| 02_activity_level.patch | レシピへの `activity_level` 挿入 | 8〜10 |
| 03_price_conversion.patch | `price` / `price_postapoc` の数値→文字列 | 40〜50 |
| 04_remove_armor_enchants.patch | `ARMOR_BALLISTIC` / `ARMOR_BULLET` の削除 | 2〜4 |
| 05_remove_invalid_fields.patch | `method`, `bashing`, `armor_*` 等の無効フィールド削除 | 10〜20 |
| 06_manual_fixes.patch | 名称形式修正、special_attacks 削除、see_cost 追加、EOC 修正、field_type 修正、rot_spawn 修正、flags.json 新規、その他 | 残り全て |

## リスクと対策

| リスク | 対策 |
|---|---|
| スクリプト適用後の中間状態と実際の 0I が一致しない | 最終的に `diff -rq` で完全一致を検証。不一致がある場合は該当箇所を 06_manual_fixes.patch に吸収 |
| パッチ適用時に行番号ずれで失敗 | `diff -ruN -U3` で十分なコンテキストを確保。`patch` コマンドのファジーマッチで対応 |
| 複数パッチが同一ファイルの近接行を変更 | 順次適用を前提とする。README に明記 |
| `remove_invalid_fields.py` のフィールドセットが 0I と完全に一致しない | スクリプト実行後の diff を確認し、過剰/不足があれば手動パッチに吸収 |
