# Calcium Carbide Popper 設計計画

## 概要

CDDAに実在する `chem_carbide`（炭化カルシウム）の説明文には「水と混ぜて密閉すれば破裂し、ゾンビの注意を逸らす大きな音が出る」とあるが、**このクラフト可能な投擲式ノイズメーカーは未実装**。これを実装する。

### `chem_carbide` の重要情報
- ID: `chem_carbide`
- デフォルト容器: `bottle_plastic_small`
- デフォルトチャージ数: 100
- 1チャージ = 6.41 mg（合計641 mg / 100）
- 説明文からの引用: *"If mixed with water and sealed, it will explode with little strength, but with a relatively loud noise that might be useful as a distraction."*

## 実装詳細

### 1. `carbide_popper`（未活性状態）

- `type`: `ITEM`, `subtypes`: `[ "TOOL" ]`
- `name`: `{ "str": "calcium carbide popper" }`
- `description`: 炭化カルシウムと水が隔壁で分離された小型容器。隔壁を破ると化学反応でアセチレンガスが発生し、圧力で容器が破裂する。
- `use_action`: `transform` → `carbide_popper_act` に変換
  - `type`: `"transform"`
  - `need_wielding`: `true`（グレネードと同様、手持ち必須）
  - `msg`: `"You break the seal, mixing the calcium carbide with water. The pressure builds rapidly…"`
  - `target_timer`: `"5 seconds"`
  - `menu_text`: `"Break seal"`
- `flags`: `[ "BOMB" ]`（爆発物として認識させる）
- 材質: `plastic`
- 重量: 軽量（50g前後、容器＋内容物）
- 体積: 50ml程度（bottle_plastic_small 相当の1/10）

### 2. `carbide_popper_act`（活性化状態）

- `type`: `ITEM`, `subtypes`: `[ "TOOL" ]`
- `name`: `{ "str": "active calcium carbide popper", "str_pl": "active calcium carbide poppers" }`
- `description`: 内部でアセチレンガスが発生しており、まもなく破裂する。今すぐ投げるべきだ。
- `countdown_action`:
  ```json
  {
    "type": "explosion",
    "explosion": {
      "power": 3,
      "shrapnel": 0
    }
  }
  ```
  - `power: 3` → 最小限の爆風（容器自体の破壊 + 至近距離の小ダメージ）
  - `shrapnel: 0` → 破片なし
- `countdown_interval`: `"5 seconds"`
- `tick_action`: `[ { "type": "sound", "sound_message": "A hissing fizz comes from the carbide popper.", "sound_volume": 0, "sound_id": "misc", "sound_variant": "lit_fuse" } ]`
- `flags`: `[ "TRADER_AVOID", "NPC_THROW_NOW" ]`（NPCに即時投擲を指示、C4の活性化状態と同パターン）

### 3. レシピ

```json
{

  "category": "CC_WEAPON",

```

- `chem_carbide` 20チャージ（約128 mg — ごく少量で十分なガス圧）
- `water` 1単位（微量の水で反応開始）
- `bottle_plastic_small` 1個（容器として消費）
- `duct_tape` 10チャージ（密封用。既存爆発物レシピと同量）
- `CUT` quality 1（ナイフなどでテープを切る）
- `autolearn: true`（単純な仕組み）
- `difficulty: 1`（最低難易度）
- `activity_level: LIGHT_EXERCISE`（軽作業。火薬を扱わないのでfirecracker同等の軽さ）

## 設計上の判断

### なぜ `countdown_action: "explosion"` を使うのか
- `chem_carbide` の説明文が "explode with little strength" と明記
- 爆発はCDDA内部で自動的にボリューム比例のノイズを生成する（`power: 3` は firecracker の `sound_volume: 20` より控えめだが、低出力爆風 + 破裂音の2段階関心誘引効果が得られる）
- `"type": "sound"` のみの場合、アイテム消費の挙動が明示的でない（爆発型はアイテムが確実に消費される）

### なぜ `shrapnel: 0` か
- プラスチック容器の破裂であり、金属破片は発生しない
- ゾンビにダメージを与えるのではなく、**注意を逸らす**のが目的

### なぜ `water` もコンポーネントに含めるか
- 反応に水が必要（化学的事実。CaC₂ + 2H₂O → C₂H₂ + Ca(OH)₂）
- 常在的なリソースでありコストとして無視できるが、レシピの説得力を高める
