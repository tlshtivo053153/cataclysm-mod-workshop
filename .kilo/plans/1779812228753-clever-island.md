# Plan: Construction Site Start Scenario

## Mod info
- **名称:** Construction Site Survivor（建設現場サバイバー）
- **ID:** `construction_site_start`
- **カテゴリ:** `scenario`
- **規模:** 小規模（新規ID: 2）
- **依存:** `dda`

## 概要
Cataclysm発生時、建設現場で作業中だったサバイバー。工具と建材が手元にあるが、現場は屋外に開かれており遮蔽物が少ない。Scenarioカテゴリは本プロジェクト初。

**建設現場の特性:** 床は土（`t_region_soil`）、遮蔽物なし。ポータブルコンクリートミキサー、ディーゼル発電機（66-70%）、小型作業車（66-70%）が手に入る可能性あり。

### 職業制限
- **許可:** `construction_worker` (Handy Man/Woman), `electrician`, `engineer_mech` (Mechanical Engineer), `mechanic` (Home Mechanic)
- **除外理由:** `handymanservice` は家庭向け出張サービス＋バン付きで建設現場に不適。`combat-engineer` は軍事系（achievement要求あり・7ポイント）。`engineer_ee` は研究室バックグラウンドで不適。

## 実装手順

1. `modinfo.json` 作成
2. `data/start_location.json` — `sloc_construction_site` 定義
3. `data/scenario.json` — `scenario_construction_site` 定義
4. `bash scripts/validate.sh mods/small/construction_site_start` で Level1 チェック
5. `bash scripts/link_mod_for_test.sh mods/small/construction_site_start` でテスト配置
6. `bash scripts/check_mods.sh` で Level2 チェック
7. CDDA起動 → 新規ゲーム → Scenario選択画面で "Construction Site Survivor" が表示され選択可能であること（Level3）
8. ゲーム開始後、建設現場に正しくスポーンすること（Level3）
