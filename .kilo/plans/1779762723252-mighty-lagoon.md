# Plan: Scrap Striker Martial Art Mod

## Overview

CDDAの小規模modとして、**新規格闘スタイル「Scrap Striker（スクラップ打撃術）」** を実装する。

本プロジェクトで未着手の `type: "martial_art"` カテゴリへの初対応。バニラの `BATONS` 武器カテゴリ（パイプ、バット、バール等）に特化した即席打撃スタイル。

---

## Design

### Concept

廃材や即席武器で戦うサバイバーが編み出した、粗野で破壊力重視の格闘スタイル。重い打撃武器の質量を活かした粉砕攻撃と、連続した素早い振り抜きを使い分ける。技術より力任せ。

### New IDs (4 IDs, fits small mod criteria)

| ID | Type | Description |
|---|---|---|
| `style_scrap_striker` | martial_art | 格闘スタイル本体 |
| `buff_scrap_striker_static` | buff (inline) | 常時発動: 鈍器ダメージ+10% |
| `tec_scrap_striker_smash` | technique | 粉砕打: ダメージ+25% / 速度-20% |
| `tec_scrap_striker_backhand` | technique | 連続打: 速度+30% / ダメージ-20% (melee 3以上) |

## Implementation Steps

### Step 1 & 2: Skip (小規模mod: 4 IDs ≤ 5, weapon_category only, no new systems)

### Step 3: Create design.md in mod directory

### Step 4: Verify references in external/cdda/

- [x] `external/cdda/data/json/martialarts.json` — BATONS category confirmed (eskrima, krav_maga, ninjutsu use it). Closest reference: bojutsu (`strictly_melee: true`, `weapon_category: ["QUARTERSTAVES"]`, `primary_skill: "bashing"`)
- [x] `external/cdda/data/json/techniques.json` — NO conflicts with `tec_scrap_*`. Clean namespace.
- [x] `external/cdda/data/json/weapon_categories.json` — BATONS category defined with proficiencies (prof_batons_familiar/pro/pro_master). 19+ weapons in category including: crowbar, pipe, baton, shillelagh, tonfa, cudgel, stick, wrench
- [x] `external/cdda/doc/JSON/MARTIALART_JSON.md` — No 0.I-specific changes to martial art schema. All fields in plan are valid.

### Step 5: Review plan (AI self-review, then proceed)

### Step 6: Implementation

Files to create:

```
mods/small/scrap_striker/
├── design.md
├── modinfo.json
└── data/
    ├── martialarts.json   (style + inline buff)
    └── techniques.json    (2 technique definitions)
```

### Step 7: Validation

- `bash scripts/validate.sh mods/small/scrap_striker` — JSON syntax
- `bash scripts/link_mod_for_test.sh mods/small/scrap_striker` — symlink to CDDA
- `bash scripts/check_mods.sh scrap_striker` — load check

### Step 8: In-game verification

1. Enable `scrap_striker` mod in world settings
2. Debug menu → Spawn a bat/pipe/crowbar
3. Debug: raise bashing skill to 4+ (autolearn triggers)
4. Switch to Scrap Striker style via `_` key (martial arts menu)
5. Test melee combat: confirm techniques trigger (smash / backhand messages appear)
6. Verify buff effects (bash damage bonus visible in @ stats)

### Step 9: Balance check

Compare to existing `style_bojutsu` (QUARTERSTAVES, bashing-based) and `style_barbaran` (allow_all_weapons). Scrap Striker should be:
- More damage-heavy than bojutsu (less finesse, more crushing)
- More restricted than barbaran (only BATONS, not all weapons)
- Damage bonus comparable to other weapon styles (10-20% normal range)
