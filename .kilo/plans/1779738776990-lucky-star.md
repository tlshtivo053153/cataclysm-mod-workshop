# formicid_sample 入手手段の追加計画（v2 — 修正版）

## 現状分析

- `formicid_sample` は `data/mutagen_ingredients.json` で `copy-from: mutagen_sample` として定義済み
- `formicid_sample` は `data/mutagen_recipes.json` の `mutagen_formicid` レシピで必須素材として使用される
- **現在は入手手段が一切存在しない**（デバッグスポーンのみで入手可能）

## 実装方針

CDDAバニラの入手パターンに倣い、以下の**2つの入手経路**を追加する。

### 1. アリ系モンスターの解剖（dissect）からの入手

**二層アーキテクチャで実装：**

- **Layer 1（新規作成）**: `formicid_sample_single`/`small`/`large`/`huge` の item_group を作成（バニラの `insect_sample_*` と同じ構造）
- **Layer 2（extend）**: `dissect_insect_sample_single` 等の **harvest 定義** に `copy-from` + `extend` で2つ目の `mutagen_group` エントリを追加（`type: "harvest"` は extend 実績あり — `external/cdda/data/json/harvest.json` 参照）

- **メリット**: モンスター個別に dissect フィールドを書き換える必要がなく、既存の全アリ系モンスター（`mon_ant`, `mon_ant_soldier`, `mon_ant_queen`, `mon_ant_acid` 等）の解剖から自動的に formicid_sample が入手可能になる
- **ドロップ量**（insect_sample のドロップは従来通り維持）:
  - `formicid_sample_single`: 1x formicid_sample
  - `formicid_sample_small`: 1-3x formicid_sample
  - `formicid_sample_large`: 3-6x formicid_sample
  - `formicid_sample_huge`: 10-20x formicid_sample
- **注意**: `dissect_only: true` により、解剖（dissect）アクションのみで入手可能。通常の屠殺（butcher）では入手不可。

### 2. 研究所の科学物資（science item_group）からの入手

- **アプローチ**: `science` item_group（distribution 型）を `copy-from` + `extend: { "items": [...] }` で拡張
- **フォールバック理由**: `lab_mutagen_ingredients_fridge` は `"subtype": "collection"` のため、CDDA 0.I では item_group の `copy-from` + `extend` が機能しない（`"subtype": "distribution"` のみ対応）
- **実績**: Magiclysm 公式mod が同ファイルで `science` を extend している実績あり（`external/cdda/data/mods/Magiclysm/itemgroups/itemgroups.json:1199-1202`）
- **ドロップ率**: `{ "item": "formicid_sample", "prob": 40, "count": [ 1, 3 ] }`（distribution 型では prob は重み付け、総 weight 約500+中の40 = 約8%の出現率）

## その他の自然な入手手段（提案）

ユーザーが要望すれば追加可能な候補：

1. **アリの巣（ant tunnels / anthills）への配置**
   - アリの巣の mapgen に `formicid_sample` を配置（アリクイーンの近くで見つかる設定）
   - 実装には mapgen の `extend` 対応が必要で、やや複雑

2. **農場/養蜂場への配置**
   - 蟻酸（formic acid）は養蜂で使われるため、農場系ロケーションの補充アイテムとして配置
   - `supplies_farming` や `farm_supply` 系 item_group への拡張

3. **科学研究所の供給品グループへの追加**
   - `supplies_science` 等の汎用科学アイテムグループに追加（prob 5-10, count [1,3]）
   - 研究所冷蔵庫より低確率だが、より多様な場所で見つかる

4. **実験室のミュータントタンク**
   - `lab_filltank_mutagen_insect` のような液体変異原タンクとして配置する案もあるが、これは formicid_sample ではなく最終製品（mutagen_formicid）向け

## 設計上の注意点

- **item_group の extend**: `item_group` は `copy-from` + `extend: { "items": [...] }` で拡張する。`"entries"` キーではなく `"items"` キーを使用する（Magiclysm 公式mod の `external/cdda/data/mods/Magiclysm/itemgroups/itemgroups.json` で実績確認済み）。**注意**: `"subtype": "collection"` の item_group は CDDA 0.I では `copy-from` + `extend` に対応しておらず、`"subtype": "distribution"` のみ可能
- **harvest の extend**: `harvest` 型は `copy-from` + `extend: { "entries": [...] }` で拡張する。バニラの `external/cdda/data/json/harvest.json` に多数の使用例あり
- **`mutagen_group`**: `type: "mutagen_group"` は `harvest_drop_type` 定義で、`drop` に指定したIDを `item_group` として解決する。`dissect_only: true` なので解剖アクション限定
- `copy-from` 先IDの実在確認:
  - `dissect_insect_sample_single` 等: `external/cdda/data/json/harvest_dissect.json:291-313` ✅
  - `science`: `external/cdda/data/json/itemgroups/science_and_tech.json:4` ✅（distribution 型、Magiclysm も使用）
- `MUTAGEN_SAMPLE` フラグは `mutagen_sample` から継承済みなので解剖システムと正常に連携する
