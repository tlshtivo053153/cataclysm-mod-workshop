# Plan: Add design.md to 7 mods in mods/small/

## Overview

7 out of 16 mods in `mods/small/` are missing `design.md`. Create one for each, following the conventions of **existing design.md files** (not `templates/design_template.md` verbatim).

**Existing convention (全mod共通):** 
- 小規模modは `spec.md` を省略しているため、`templates/design_template.md` の `### 仕様書から継承` セクションは使わず、`### 目的` / `### スコープ` を直接記述する
- 完了条件チェックボックスは `[ ]`（未検証）とする（事後ドキュメント作成のため検証状況が不明）
- ID一覧・アイテム/レシピの仕様テーブルは、既存JSONから抽出して記載する（heavy_crowbar/design.md, scrap_striker/design.md を参照）

## 各設計書の内容

各 design.md に含めるセクション:
```
### 目的 / ### スコープ / ### ターゲットバージョン / ### 依存関係
### 使用予定ID一覧 / ### 参照ファイル（実在確認済み） / ### ファイル構成
### 実装順序 / ### [アイテム等]仕様 / ### テスト手順 / ### 完了条件
```

### 1. `construction_site_start/design.md`
- **modinfo.id:** `construction_site_start`
- **目的:** 建設現場からゲーム開始する新規シナリオを追加
- **スコープ:**
  - 含む: シナリオ1種 (`scenario_construction_site`), スタート地点1種 (`sloc_construction_site`)
  - 含まない: アイテム・レシピ・モンスター追加
- **ID一覧:** scenario_construction_site, sloc_construction_site
- **JSONファイル:** modinfo.json, data/scenario.json, data/start_location.json
- **CDDA参照 (要確認):** `external/cdda/data/json/scenarios/` — シナリオフォーマット。scenario.json で参照している professions (construction_worker, electrician, engineer_mech, mechanic) の実在確認先 → `external/cdda/data/json/professions/`
- **注意点:** アイテム/レシピを持たないシナリオ専用modのため、`### アイテム仕様` のようなセクションは不要。代わりにシナリオ・開始地点のフィールド仕様テーブルを書く。
